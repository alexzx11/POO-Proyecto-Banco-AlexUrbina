## Instrucciones para compilar y ejecutar
1. Descargue los 4 archivos `.java` de este repositorio.
2. Cree un nuevo proyecto en Apache NetBeans y agregue estos archivos dentro de un paquete llamado `tareal_alexurbina`.
3. Abra el archivo principal `Main.java`.
4. Presione la tecla **F6** para compilar y ejecutar.
